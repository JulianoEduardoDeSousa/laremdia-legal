# laremdia-legal

Páginas legais estáticas do app **Lar em Dia** (`br.com.laremdia.lar_em_dia`), publicadas via GitHub
Pages em https://julianoeduardodesousa.github.io/laremdia-legal/, exigidas pela ficha do Google Play.

## Conteúdo

- `index.html` — página inicial com links para as demais páginas e download do Windows.
- `privacy-policy.html` — Política de Privacidade.
- `delete-account.html` — Excluir conta e dados.
- `terms-of-service.html` — Termos de Uso.
- `icon.png` — ícone do app.

## Publicação

1. Criar repositório `laremdia-legal` na conta GitHub `JulianoEduardoDeSousa`.
2. Enviar (`git init`, `git add`, `git commit`, `git push`) o conteúdo desta pasta.
3. Ativar GitHub Pages nas configurações do repositório (branch `main`, pasta raiz).
